# 抽号机 · Number Drawer

软件工程 2502 班专用的课堂随机点名 / 抽号小工具。纯前端实现，无需安装，打开即用。

## 功能特性

- 🎲 **随机抽取**：抽取 1~30 人，支持数字滚动「抽奖式」动画效果
- ⌨️ **键盘快捷键**：`Space`/`Enter` 抽取、`R` 重置、`H` 查看记录
- 📋 **抽取记录**：自动保存最近 50 次抽取历史
- ✨ **粒子背景**：动态粒子连线背景，课堂展示效果好
- 🏷️ **名单高亮**：抽取结果在底部全员名单中高亮标注

## 快速开始

直接双击打开 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 修改名单

名单在 `js/students.js` 中，直接增删改数组即可，刷新页面生效：

```js
window.STUDENTS = [
  "张三", "李四", "王五",
  // ...
];
```

> ⚠️ **隐私说明**：本仓库刻意**不包含学号**，只保留姓名（学号+姓名属于个人隐私，公开仓库可能给同学带来风险）。如果实际使用中需要展示学号，请将仓库设为 **private**。

## 技术栈

原生 HTML + CSS + JavaScript，无任何依赖：

- `index.html` — 页面结构
- `css/style.css` — 赛博朋克风格样式
- `js/app.js` — 抽号逻辑（Fisher-Yates 洗牌算法）
- `js/students.js` — 学生名单配置（外置，方便维护）
